กฎที่ต้องจำ
❌ ห้ามทำ
  • เขียน state ใน views/ (ยกเว้น UI state เช่น toggle dropdown)
  • เขียน business logic ใน component/
  • ดึง API ตรงใน component หรือ view
  • คัดลอก EXP_DATA, GROUP_LABELS ไปใส่ใน component อื่น
  • สร้าง mockData ใหม่แยก — ให้ import จาก models/mockData.js
✅ ทำแบบนี้
  • เพิ่ม constants ใหม่ใน models/ ก่อนเสมอ
  • สร้าง hook ใน viewModels/ ถ้ามี state ซับซ้อน
  • ใส่ service function ใน api/ ถ้าต้องดึงข้อมูล
  • แยก shared UI เป็น component/ ถ้าใช้ใน 2+ view
  • สร้าง folder ใน views/ สำหรับแต่ละ page
